# ropez - Rope implementation in Zig

Inspired by [ropey](https://github.com/cessen/ropey) and [this blog post](https://blog.cessen.com/post/2020_04_03_ropey_things_i_would_do_differently), as well as [Zed](https://zed.dev) and [xi-editor](https://github.com/xi-editor/xi-editor), I decided to write a rope implementation in Zig.

Primarily created for zix - modal editor.
